МОЙ ПУТЬ К 90 КГ — Android Studio проект

Что добавлено:
- Распознавание объектов на фото с помощью Google ML Kit Image Labeling.
- После выбора фото приложение показывает несколько наиболее вероятных меток с уверенностью.
- Найденные названия подставляются в описание еды, которое можно отредактировать.

Важно:
- Это общее распознавание изображений, а не специализированный диетологический ИИ.
- Оно может распознать, например, «banana», «pizza» или «food», но не определяет надёжно ингредиенты, массу порции или калории.
- Калорийность нужно проверить и указать/оценить отдельно. Не воспринимай результат как точное измерение.
- Анализ выполняется на телефоне через ML Kit; для сборки Gradle скачает библиотеку.
- Фото не отправляется в сторонний облачный сервис этим кодом.

Как собрать APK:
1. Установи Android Studio на компьютер.
2. Распакуй архив.
3. Открой папку MyPath90_Android через File > Open.
4. Дождись Gradle Sync и загрузки зависимости ML Kit (нужен интернет).
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Установи app-debug.apk на Samsung.

Требования:
- Android Studio с Android Gradle Plugin 8.6.1 (или совместимая версия).
- SDK Platform 35.

Новая RPG-система:
- Уровни и звания персонажа за накопленный опыт (каждые 100 XP — новый уровень).
- Ежедневные задания: записать еду (+20 XP), записать вес (+15 XP), уложиться в цель калорий (+25 XP).
- За дополнительные записи еды начисляется небольшой бонус, ограниченный тремя бонусами в день.
- Полученный опыт сохраняется локально. Пропуск дня не отнимает XP.

Новая система достижений:
- Первый рацион, 7 и 30 дней с записями еды.
- Первая запись веса.
- Снижение на 1, 5 и 10 кг от стартового веса (фиксируется при первой записи веса).
- Серия из 7 дней подряд с дневником.
- За каждое достижение XP начисляется один раз.

СБОРКА APK БЕЗ ANDROID STUDIO (В ОБЛАКЕ GITHUB ACTIONS):
1. Создай бесплатный аккаунт на github.com и новый репозиторий (например, mypath90).
2. Распакуй архив на компьютере или телефоне. В репозиторий нужно загрузить содержимое папки проекта, сохраняя папку MyPath90_Android и папку .github/workflows в корне репозитория.
3. На странице репозитория нажми Add file > Upload files. Загрузи папку MyPath90_Android целиком и папку .github (в ней workflow). Если веб-интерфейс не позволяет загрузить скрытую папку .github, создай файл вручную через Add file > Create new file и назови его .github/workflows/build-apk.yml, затем вставь содержимое файла из архива.
4. Нажми Commit changes. GitHub автоматически запустит сборку.
5. Открой вкладку Actions, выбери последний запуск Build Android APK.
6. После статуса зелёной галочки скачай артефакт MyPath90-debug-apk. Внутри будет app-debug.apk.
7. Перенеси APK на Samsung, открой файл и разреши установку из этого источника, если Android попросит.

Можно также вручную запустить сборку: Actions > Build Android APK > Run workflow.
Сборка выполняется на серверах GitHub; Android Studio и Android SDK на твоём компьютере не нужны. Нужен интернет. На бесплатном GitHub есть лимиты минут Actions; для небольшого проекта обычно достаточно. Не публикуй в репозитории личные данные или реальные медицинские сведения.
