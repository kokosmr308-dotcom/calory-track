# Счётчик калорий — Android

Новый базовый Android-проект. Название приложения: **Счётчик калорий**.

## Что уже реализовано
- Дневник питания по датам с разделами «Завтрак», «Обед», «Ужин», «Перекус».
- Ручное добавление продукта и веса в граммах.
- Расчёт калорий и БЖУ по значениям на 100 г.
- Дневная цель калорий и индикатор прогресса.
- Удаление записи.
- Светлая и тёмная тема.
- Ежедневные мягкие задания: разнообразие продуктов, фрукты/овощи, источник белка и регулярная запись приёмов пищи.
- Локальное хранение на устройстве, без аккаунта и облачной синхронизации.

## Сборка через GitHub
1. Создайте пустой репозиторий на GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория (включая `.github`).
3. Откройте вкладку **Actions**.
4. Выберите **Build Android APK** → **Run workflow**.
5. Дождитесь зелёного статуса сборки.
6. Откройте завершённый запуск и скачайте файл из **Artifacts**.

## Сборка локально
Нужны Android Studio и JDK 17. Откройте папку проекта в Android Studio и выполните Gradle-задачу `assembleDebug`.
Если Gradle Wrapper не добавлен, Android Studio может предложить создать/настроить его.

## Права и безопасность
- Файл workflow находится в `.github/workflows/build-apk.yml`.
- Для GitHub Actions не нужны секреты или ключи подписи.
- Полученный debug APK предназначен для установки и тестирования. Для публикации в Google Play потребуется отдельная release-сборка и собственный ключ подписи.
- Не загружайте в репозиторий пароли, токены и приватные ключи.

## Честно о текущем объёме
Это рабочая стартовая версия дневника, а не завершённая «топовая» версия из полного списка пожеланий.
Распознавание еды по фото, база брендов/ресторанов, RPG-персонаж, уровни, достижения, графики веса и резервное копирование пока не реализованы. Выполнение задания про фрукты и овощи определяется по ключевым словам в названии продукта, поэтому иногда потребуется точнее назвать продукт. Их можно добавлять следующими этапами.
